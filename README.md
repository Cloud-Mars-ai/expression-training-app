# 表达能力训练 APP

当前目录已进入“真实可用最小闭环”的共同基础阶段。现有演示成品仍位于 `app/`，可通过 `启动试用版.bat` 打开；开发代码与后续服务端代码按以下边界组织：

- `frontend/`：React 前端。
- `server/`：Attempt、上传、转写和评分服务。
- `contracts/`：前后端共享的唯一数据与 API 契约。
- `docs/architecture/`：状态机、目录所有权、依赖与集成顺序。

当前版本已在共同基础上打通真实录音、上传、转写校对和证据型分析闭环。原始音频只进入本机 ASR；用户确认后的转写、当前题目和评分标准通过服务端发送到 DeepSeek API。

## 当前新增能力

- 全局白色浅色 / 淡黄莫兰迪主题，并让作答与复盘页面跟随主页主题。
- 真实录音上传后由本机 ASR Provider 转写；运行环境不再默认使用 Mock 转写。
- 用户确认转写后，由 DeepSeek `deepseek-chat` 生成证据型反馈；API Key 只从服务端 `.env.local` 读取。
- 未配置 Provider 或调用失败时进入技术失败状态，不编造录音内容、不产生低分。
- 接入 `07-全网蒸馏研究/topics.json` 的 80 道训练题，可按 6 类筛选、搜索并贯穿完整训练流程。
- 题库运行快照保留来源编号、安全提示、时效和更新标记；执行 `npm run sync:topics` 可重新校验与同步。

Provider 配置示例见 `.env.example`，详细步骤见 `使用说明.md`。
